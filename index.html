le 15 novembre · CasaWarden
post-hackathon thoughts: though we didn't win, i learned a lot from this hackathon experience! definitely a huge shoutout to my teammates grace, saanvi, and rishi, we all worked so hard and learned so much, especially since none of us have really worked with cybersecurity before. learning about how devices can be compromised through wifi networks was honestly quite scary, since we are all vulnerable to those type of attacks. though, with the software we built: CasaWarden, we accomplished exactly what we wanted, quarantined those compromised devices so attackers cannot access any other personal devices :P! i also learned how to work with raspberry pi on a more on-hands manner, along with the arduino (that was gifted thanks to sponsors!!!), having the leds react to when the system is healthy/attacked/quarantined was pretty fun!
